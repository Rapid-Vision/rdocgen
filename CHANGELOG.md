# Changelog

All notable changes to this project will be documented in this file.

## [0.1.1] - 2026-02-15
### Fixed
- Fixed | escaping in class attribute types
- Fixed comments after multiline type annotations in function arguments


## [0.1.0] - 2026-02-03
### Added
- AST-based parser that extracts classes, functions, enums, and inline comments.
- Markdown renderer with VitePress-friendly anchors and sections.
- CLI for file or directory generation with filtering and sorting flags.
- Safe cleanup behavior with `--clean`, `--force`, and `--dry-run`.
- Minimal unit tests for parser, renderer, and exporter safety.
